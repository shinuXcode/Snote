## Audit order and gates

1. Canvas input/rendering, stroke model/codec, persistence and note restoration.
2. Editor routes and lifecycle; trace all callers before splitting large widgets.
3. PDF open/render/annotation/scroll/cache/disposal paths.
4. Dependency declarations, lockfile, plugin registration, manifests and generated merged manifests.
5. CI, beta and release workflows, including output artifacts and secrets handling.
6. Website routes, API handlers, assets, CSS and build configuration.
7. Remaining tools/settings/features, tests and docs.

No runtime change should be made solely to reduce source-file size. For every proposed code or dependency change, record callers, platform/runtime dependencies, focused tests, full relevant CI, and comparable artifact/performance measurements. Preserve stylus latency/pressure/palm rejection, stroke persistence/undo-redo, offline-first data, note restoration, PDF rendering/navigation, and cross-platform support.

## Confirmed findings and merged fixes

- **PR #39 — merged:** debug frame-drop accounting now uses the display refresh rate; the overlay calls its handler-to-frame timing `Input→frame`, not physical stylus latency. Regression tests cover 60 Hz, 120 Hz and invalid-rate fallback.
- **PR #40 — merged:** removed unused direct `flutter_riverpod` and `collection` declarations after tracked Dart import scans. Measured size changes are tiny and do not demonstrate material savings.
- **PR #41 — merged:** beta Android setup now validates maintained native sources rather than overwriting MainActivity with a duplicate capture-only implementation that could drop the ringtone channel.
- **PR #43 — merged:** InkInputPipeline retains the canonical pen-up timestamp; regression test covers a stale pen-up event.
- **PR #44 — merged:** removed `BezierSmoother` and `InkDynamics` after repository-wide source/test reference checks found no callers. Total source removed: 1,541 bytes; no APK saving is claimed.
- **PR #45 — merged:** corrected over-escaped local-file sanitizer; digits and letters are preserved, path separators/control bytes are replaced. Existing paths previously changed by the old sanitizer are not automatically rewritten.
- **PR #46 — merged:** platform-specific SQLite factory initialization added for Linux/Windows FFI and web IndexedDB, with generated web SQLite runtime assets. Linux/Windows in-memory read/write smoke test passed; browser persistence runtime still needs verification.
- **PR #42 — in progress:** profile-mode Android emulator benchmark workflow is still running. No frame/memory/PDF numbers are recorded until its JSON log artifact is available.
- **Memory candidates, not proven leaks:** Editor V2 raster caches have count/byte bounds, but PDF source-byte and background/image byte caches lack obvious local caps. Profile large notes/PDFs before modifying.
- **Database portability:** FFI/web factories are now initialized, but the browser IndexedDB path and full app-level offline restore still need a browser runtime check.

## Device/emulator measurement blocker

The repeatable protocol is in `docs/phase-six-performance-memory-baseline.md`. The emulator workflow is running a synthetic stylus workload, process RSS sampling, and PDF open/first-page raster measurement. Synthetic events are not physical event-to-photon latency or real palm rejection; the full PDF annotation UI, scrolling/zoom, and persisted annotation workflow are still not proven by the library-level PDF measurement. Physical tablet traces remain outstanding.
