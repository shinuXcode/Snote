## Device/emulator measurement blocker

No physical-device or emulator trace was available during this repository review. Consequently, actual event-to-visible-ink latency, refresh-rate-aware frame percentiles, memory growth during long writing sessions, and large-PDF open/scroll memory remain **blocked / unmeasured**. CI compilation and widget tests do not establish these runtime measurements. The repeatable protocol is in `docs/phase-six-performance-memory-baseline.md`; record device/build/document metadata and at least three runs before accepting a performance optimization.
